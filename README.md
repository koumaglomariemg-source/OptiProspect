# OptiProspect

OptiProspect est une solution de gestion et de suivi de la prospection commerciale, disponible sur le Web (PWA) et sur Mobile.

## Fonctionnalités
- Gestion des prospects, contacts et rendez-vous
- Suivi des opportunités et relances commerciales
- Authentification sécurisée et gestion des accès
- Tableau de bord synthétique

## Technologies utilisées
- **Mobile :** Flutter (Dart)
- **Frontend Web :** React, HTML5, CSS3 / PWA
- **Backend :** Node.js, Express
- **Base de données :** MySQL

## Installation et lancement

### Prérequis
- Node.js (v18+)
- MySQL
- Flutter SDK & Android Studio / VS Code
